What is KYC:
KYC stands for Know Your Customer. It is the process of verifying a customer's identity using valid documents before providing financial or business services. The main purpose of KYC is to prevent fraud, money laundering, identity theft, and other illegal activities while ensuring compliance with regulatory requirements.

What does a KYC Specialist do:
A KYC Specialist verifies customer information and documents, ensures records are accurate and complete, follows company compliance procedures, maintains confidentiality, and escalates any suspicious or incomplete cases for further review.

What is a Process Associate?
A Process Associate is responsible for ensuring that daily business operations run smoothly by processing information accurately, following company procedures, maintaining records, and completing tasks on time.

What is Data Processing?

Campus Placement Operations Dashboard (Power BI + Excel)

"The Campus Placement Operations Dashboard is a Power BI and Excel-based analytics project developed to analyze and visualize our college's placement performance. The main objective was to help students and college management understand placement trends, company participation, salary packages, and department-wise placement statistics.
This was a team project involving 15 members, and I worked as the team leader. I divided the team into five groups responsible for data collection, data cleaning, data analysis, dashboard development, and report generation. Along with leading the team, I was personally involved in the data cleaning process and ensured smooth collaboration throughout the project.
The dataset contained approximately 55,000 placement records with columns such as Student Name, Department, Company Name, Placement Status, Package Offered, Placement Year, and Contact Number. During data cleaning, I helped remove duplicate records, handled missing values, standardized inconsistent text formatting, and validated the data to ensure accuracy and consistency.
Initially, we attempted to clean the data using Power Query in Power BI, but we faced issues during the data preparation process. To resolve this, we cleaned and validated the entire dataset in Excel before importing the cleaned data into Power BI. This improved the reliability of our dashboard.
The dashboard included KPI cards such as Highest Package, Average Package, and Total Students Placed. We also created bar charts, line charts, pie charts, and slicers to analyze department-wise placements, yearly placement trends, top recruiting companies, and package distributions.
The final dashboard enabled students and college management to quickly understand placement performance, identify recruitment trends, compare departments, and make informed decisions based on accurate placement data.

Seconf project::

My project is called the Real-Time API Data Integration & Analytics Dashboard. The main objective of this project was to automate the collection of economic data from the World Bank API and visualize it through an interactive Power BI dashboard instead of manually downloading datasets.
I used the publicly available World Bank REST API to collect data for multiple countries, including India, the United States, China, Germany, and Brazil. The project retrieves key economic indicators such as GDP, GDP per Capita, Inflation Rate, GDP Growth, Population, CO₂ Emissions, and Life Expectancy.
For data extraction, I used Python with the Requests library to fetch the API responses. Since the API returns data in JSON format, I used the Pandas library to clean and transform the data. This included flattening the nested JSON structure, handling missing values, standardizing the data, merging multiple datasets, and converting them into a structured master CSV file suitable for analysis.
The cleaned CSV file was then imported into Power BI, where I created an interactive dashboard. The dashboard includes KPI cards for Total GDP, Average GDP per Capita, Average Inflation Rate, and Average GDP Growth. I also created line charts to analyze GDP trends over time, bar charts for country-wise GDP comparisons, and slicers that allow users to filter the dashboard by country and year.
The biggest challenge in this project was converting raw API responses into a clean tabular format because the API data was nested and spread across multiple responses. I solved this by using Python and Pandas to automate the transformation process before loading the data into Power BI.
The final dashboard provides a clear overview of global economic performance, enabling users to compare countries, analyze economic trends over time, and make data-driven decisions through interactive visualizations.
